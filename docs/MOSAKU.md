# 茂作 (Mosaku)

『きこりの与作』（エポック カセットビジョン）メカニクスのオマージュ。オリジナル資産は使用しない。

## Core loop

1. 左右移動し、斧で木の**地面接地点**を削る（近い距離のみ）
2. 片側 **5回**で半分まで。途中は**色変化**（橙→赤）、片側完了で**その側の根本ドットが消える**。両側で木全体が点滅消滅
3. **左右とも半分**まで削ると点滅して消える
4. **2本とも**消すと面クリア
5. 敵: イノシシ（**画面端から突進＋突進音**）／**マムシ（地面下から出現して這う）**／鳥フン・枝

解像度は 75×60。キャラシルエットは μPD777-005（きこりの与作）Pattern ROM の形に寄せたオマージュ（7〜8ドット規模・斧はシアン）。  
参考: [CVS ODYSSEY 与作](http://www.ne.jp/asahi/cvs/odyssey/videogames/cv/soft/yosaku/)、[小口氏 Pattern ROM](https://www.oguchi-rd.com/777/ROM%20Dump/777-005%20Yosaku/Pattern%20ROM/Yosaku%20Pattern%20ROM%20Contents.pdf)、[プレイ動画](https://youtu.be/HpaIb2Ptygs)
4. マムシ・イノシシ: 斧で撃破 or ジャンプ回避。接触でミス
5. 鳥は倒せない。フン／枝で約 5 秒しびれ（移動・斧不可）
6. ライフ尽きでゲームオーバー。ミス時は天使昇天＋葬送曲オマージュ
7. 通常モードとタイムアタック

## Stages

- 1面あたり目安 1〜3 分
- 全面クリア: 慣れ約10分 / 初見約30分
- 面が進むと敵速度・出現頻度・同時脅威が増える
- 一部面は夜（ホラー寄りビジュアル）

## Modes

- **Story**: 面クリア間に短い ADV（笑い／恋愛／ホラー）
- **Time Attack**: ADVなし。2本倒すまでの時間競争（1面固定）

## Controls

`docs/HARDWARE.md` の入力表に従う。

PC推奨: **A/D 移動・左クリック斧・右クリック／Space ジャンプ**。  
（Zは使いにくい。N/Mも遠いので主入力にしない。F をキーボード斧の予備に。）

## Visual

与作スクショ準拠: 黒空・ネオングリーン地面・緑の三角松・灰幹。  
キャラは**1色シルエット**（茂作=橙、斧=シアン、イノシシ=マゼンタ）。  
描画は `src/games/mosaku/cvDraw.ts` + エンジンの三角／斜め線 API。

## Animation

茂作は idle / walk / chop(上げ→振り下ろし→戻し) / jump / stun。  
斧ヒットは振り下ろし、敵ヒットは振り下ろし〜戻し。  
参考: [きこりの与作プレイ動画](https://youtu.be/HpaIb2Ptygs)
