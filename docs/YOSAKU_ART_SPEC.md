## 1. ハード描画の絶対条件（ここを守る）

### 1.1 解像度・スプライト

| 項目 | 値 |
|------|-----|
| 論理解像度 | **75 × 60** |
| 基本パターン | **7×7**（一部 **8×7**）※Pattern ROM シート上は 8 列グリッドで見られる |
| 色 | キャラ単位でほぼ **1色**（斧だけシアン等の別色） |
| 同時スプライト | 実機は厳しいが、本プロジェクトはソフト制約（枚数ゆるめ） |

### 1.2 斜め（必須・最重要）

カセットビジョン／μPD777 は矩形ドットに加え、**斜めドット／平行四辺形表示**を使う。

本プロジェクトで「斜めを使う」とは次を指す（いずれも必須対象）:

1. **階段1ドットの斜線**（例: Pattern `31h` / `34h` のような ＼ ／）
2. **斜めに組んだ斧柄**（振りかぶり・振り下ろし）
3. **三角ベタ／台形の葉**（キャノピの斜辺。滑らかパス可だが、論理上は斜めエッジ）
4. **地面・イノシシ等の斜めシルエット**（平行四辺形ボディ、斜め足・牙）

**禁止:** 矩形の積み上げだけで斜めを「っぽく見せない」。  
斜めが必要な部位は、仕様の「使用パターン／描画API」欄に必ず `diag` / `triangle` / `para` を書く。

### 1.3 描画API対応（実装時）

| 仕様キーワード | Renderer API |
|----------------|--------------|
| `rect` | `fillRect` / タイル |
| `diag` | `drawDiagThick`（表示解像度で滑らかな斜線でも可） |
| `triangle` | `fillTriangle` / `fillPine` |
| `para` | `fillParallelogram` |
| `pattern` | 8×8（または7×7）ビットマップを色付きで描く |

## 2. 画面全体レイアウト（スクショ準拠）

```
Y=0 ─────────────────────────
  HUD: 左に大きなシアン数字（残機）、右に緑のスコア／面
  空: 黒ベタ
  木×2（左右）: 橙〜金の葉（三角／台形）＋淡色の幹
  与作: 橙1色＋シアン斧
  敵: イノシシ（横）／マムシ（地面から）／鳥＋フン／枝
Y≈48 ── 緑の地面帯（画面下約1/5）──
Y=59 ─────────────────────────
```

- 幹の「切れる場所」は **地面と接する根本**（左右それぞれ）。
- 木は画面に **2本**（CV版。AC版は3本）。

## 3. 茂作（与作）— プレイヤー

### 3.1 見た目

| 項目 | 仕様 |
|------|------|
| 色 | 体・頭・足 = **オレンジ1色**。斧 = **シアン**（別レイヤ） |
| 規模 | おおよそ **8×8〜8×12** 論理ドット（Pattern ROM セル規模） |
| 頭 | **2×2** の塊 |
| 胴 | 細い縦（1〜2ドット幅） |
| 足 | 開脚。歩行で L 字の足が入れ替わる |
| 斧（待機） | 体の前方に **縦のシアン棒**＋先端が少し太い／L 字（スクショ） |

### 3.2 アニメ（Pattern ROM 対応・右向き）

| 状態 | Pattern目安 | 斜め | 説明 |
|------|-------------|------|------|
| idle | 10h 系 | 斧は縦（`rect`） | 開脚立ち、斧を体前に立てる |
| walk A/B | 11h–12h 系 | 足の形変化 | 足が前後に開く。斧は基本立てたまま |
| **swing wind-up** | **13h / 1Bh** | **必須 `diag`** | 斧柄が肩から斜め後ろ上へ。斧頭は頭の後ろ上方 |
| **swing strike** | **14h / 1Ch** | **必須 `diag`** | 斧が前方〜斜め下へ。**先端が木の根本（地面接点）に届く** |
| recover | 13h寄り | `diag` | 斧が上に戻る軌道（イノシシ判定用） |
| jump | （推定） | 足を縮める | 入力にわずかなラグあり |
| stun | （推定） | — | フン／枝ヒットで約5秒硬直 |
| death angel | （推定） | 翼に `diag` 可 | 天使姿で上昇＋葬送行進曲 |

※左右は鏡像（18h–1Ch 系）。

### 3.3 斧モーションの時間感（ルールと一体）

1. ボタン直後はすぐ出ない（**短いラグ**＝振りかぶりが見える）
2. 振り下ろしで木の根本にヒット
3. **戻り（recover）** の軌道でも敵に当たる（特にイノシシ）

### 3.4 未確定（ユーザー指摘待ち）

- [ ] 待機時の斧が「縦L」か「肩に担ぎ」か（スクショは縦L寄り）
- [ ] ジャンプ中の斧位置の正確な形
- [ ] 天使スプライトの正確な Pattern ID

## 4. 木

### 4.1 見た目

| 部位 | 仕様 | 斜め |
|------|------|------|
| 葉（キャノピ） | 上辺が広く下にすぼまる **三角／台形**。色は橙〜金（スクショ）または緑（資料により差） | **必須 `triangle`**（斜辺） |
| 葉下縁 | Pattern `1Eh` 系: ジグザグ／市松の下縁 | 部分的に `diag` |
| 幹 | **2ドット幅**程度の縦棒。淡いピンク／灰白 | `rect` |
| 地面との接点 | 切り判定・変色の主領域 | — |
| 根元の斜面タイル | Pattern `65h`/`66h` のような階段三角 | **必須 `triangle`/`diag`**（使う場合） |

### 4.2 切断表現（本プロジェクト合意済み＋原作）

| 項目 | 原作（資料） | 本プロジェクト（ユーザー指示） |
|------|--------------|--------------------------------|
| 回数 | 左右各7回で片側切断、計14で倒木 | **片側5回で半分まで**。両側半分で消える |
| 見た目 | 当たった部分が**変色** | 根本の接地ドットが **橙→赤** に変色（削れ表現） |
| 倒木後 | 倒れる／消える | **点滅して消える**＋消滅音 |

## 5. イノシシ

### 5.1 見た目

| 項目 | 仕様 |
|------|------|
| 色 | **マゼンタ／ピンク1色** |
| 形 | 横長の胴。Pattern `40h`/`41h` 系のずんぐり＋移動で1ドットシフト |
| 斜め | 胴は **`para`（平行四辺形）** または斜めに組んだ塊。牙・鼻先に **`diag`** |
| 足 | 短い脚。走行2コマ |

### 5.2 動き・やられ（資料＋動画で確認すべき点）

| 項目 | 仕様 |
|------|------|
| 出現 | 画面端から与作めがけて突進 |
| 接触 | 即ミス（天使） |
| 回避 | ジャンプ可（CV版で追加） |
| **撃破** | 振り下ろし直撃より、**早めに振って「斧が戻る」タイミングで当てる**（iyatsue 記述） |
| 撃破演出 | 消失／短い点滅／跳ね（**要動画確認** → 下記チェック） |
| 難易度 | 面が進むと極端に高速化 |

## 6. マムシ（地面から出る蛇）

### 6.1 見た目

| 項目 | 仕様 |
|------|------|
| 色 | マゼンタ系1色（スクショのギザギザ） |
| 出現 | **地面の下から這い出る**（縦にせり上がる） |
| 形 | ギザギザ／鋸歯。L字セグメント（Pattern 2Ch 系）の連結 |
| 斜め | 鋸歯エッジに **`diag` 必須** |

### 6.2 動き

| 項目 | 仕様 |
|------|------|
| フェーズ1 | 地面から上昇（emerge） |
| フェーズ2 | 地上を横に移動（這う） |
| 接触 | 即ミス |
| 撃破 | 斧（向き方向）／ジャンプ回避 |

## 7. 鳥・フン・枝

| 対象 | 見た目 | 動き | 斜め |
|------|--------|------|------|
| 鳥 | Pattern `5Dh`/`5Eh` 系。翼の開閉2コマ | 上空を左右に飛ぶ。倒せない | 翼に `diag` 可 |
| フン | 小さな塊（1〜数ドット） | 落下。当たると約5秒しびれ | — |
| 枝 | 短い棒／斜め棒 | 木を切ると落下。しびれ | **`diag` 推奨** |

## 9. 現行実装との差分（問題点・直す約束）

| 項目 | 現状（問題） | 仕様上の正解 |
|------|--------------|--------------|
| 斜め | **使っていない／不足**（ユーザー指摘） | 斧・葉・イノシシ・マムシで `diag`/`triangle`/`para` を必ず使う |
