## 1. ハード描画の絶対条件（ここを守る）

### 1.1 解像度・スプライト

| 項目 | 値 |
|------|-----|
| 論理解像度 | **75 × 60** |
| 基本パターン | **7×7**（一部 **8×7**）※Pattern ROM シート上は 8 列グリッドで見られる |
| 色 | キャラ単位でほぼ **1色**（斧だけシアン等の別色） |
| 同時スプライト | 実機は厳しいが、本プロジェクトはソフト制約（枚数ゆるめ） |

### 1.2 斜め（必須・最重要）

カセットビジョン／μPD777 は矩形ドットに加え、**斜めドット／平行四辺形表示**を使う。

本プロジェクトで「斜めを使う」とは次を指す（いずれも必須対象）:

1. **階段1ドットの斜線**（例: Pattern `31h` / `34h` のような ＼ ／）
2. **斜めに組んだ斧柄**（振りかぶり・振り下ろし）
3. **三角ベタ／台形の葉**（キャノピの斜辺。滑らかパス可だが、論理上は斜めエッジ）
4. **地面・イノシシ等の斜めシルエット**（平行四辺形ボディ、斜め足・牙）

**禁止:** 矩形の積み上げだけで斜めを「っぽく見せない」。  
斜めが必要な部位は、仕様の「使用パターン／描画API」欄に必ず `diag` / `triangle` / `para` を書く。

### 1.3 描画API対応（実装時）

| 仕様キーワード | Renderer API |
|----------------|--------------|
| `rect` | `fillRect` / タイル |
| `diag` | `drawDiagThick`（表示解像度で滑らかな斜線でも可） |
| `triangle` | `fillTriangle` / `fillPine` |
| `para` | `fillParallelogram` |
| `pattern` | 8×8（または7×7）ビットマップを色付きで描く |

## 2. 画面全体レイアウト（スクショ準拠）

```
Y=0 ─────────────────────────
  HUD: 左に大きなシアン数字（残機）、右に緑のスコア／面
  空: 黒ベタ
  木×2（左右）: **黄の葉**（階段三角／台形）＋**白〜灰白の幹**
  与作: 橙／黄1色＋シアン斧
  敵: イノシシ（**画面端から**横突進）／マムシ（地面から）／鳥＋フン／枝
Y≈48 ── 緑（またはシアン系）地面帯 ──
Y=59 ─────────────────────────
```

- 幹の「切れる場所」は **地面と接する根本**（左右それぞれ）。切れた部分はドット消失。
- 木は画面に **2本**（CV版。AC版は3本）。
- 葉色: 添付スクショ（ラベル付き面）で **黄**。緑葉のキャプチャもあるが、今回の添付優先で黄。

## 3. 茂作（与作）— プレイヤー

### 3.1 見た目

| 項目 | 仕様 |
|------|------|
| 色 | 体・頭・足 = **オレンジ1色**。斧 = **シアン**（別レイヤ） |
| 規模 | おおよそ **8×8〜8×12** 論理ドット（Pattern ROM セル規模） |
| 頭 | **2×2** の塊 |
| 胴 | 細い縦（1〜2ドット幅） |
| 足 | 開脚。歩行で L 字の足が入れ替わる |
| 斧（待機） | 体の前方に **縦のシアン棒**＋先端が少し太い／L 字（スクショ） |

### 3.2 アニメ（Pattern ROM 対応・右向き）

| 状態 | Pattern目安 | 斜め | 説明 |
|------|-------------|------|------|
| idle | 10h 系 | 斧は縦（`rect`） | 開脚立ち、斧を体前に立てる |
| walk A/B | 11h–12h 系 | 足の形変化 | 足が前後に開く。斧は基本立てたまま |
| **swing wind-up** | **13h / 1Bh** | **必須 `diag`** | 斧柄が肩から斜め後ろ上へ。斧頭は頭の後ろ上方 |
| **swing strike** | **14h / 1Ch** | **必須 `diag`** | 斧が前方〜斜め下へ。**先端が木の根本（地面接点）に届く** |
| recover | 13h寄り | `diag` | 斧が上に戻る軌道（イノシシ判定用） |
| jump | （推定） | 足を縮める | 入力にわずかなラグあり |
| stun | （推定） | — | フン／枝ヒットで約5秒硬直 |
| death | 添付スクショ | — | **青い幽霊（十字）＋頭に黄色い輪（わっか／光輪）必須**。上昇＋葬送行進曲。翼付き天使は使わない |
| idle 接地 | — | — | **両足の最下ドットが地面帯の直前行に接する**（浮かせない） |

※左右は鏡像（18h–1Ch 系）。

### 3.3 斧モーションの時間感（ルールと一体）

1. ボタン直後はすぐ出ない（**短いラグ**＝振りかぶりが見える）
2. 振り下ろしで木の根本にヒット
3. **戻り（recover）** の軌道でも敵に当たる（特にイノシシ）

## 4. 木

### 4.1 見た目

| 部位 | 仕様 | 斜め |
|------|------|------|
| 葉（キャノピ） | **階段三角**（3段ほど）。色は **黄（パレット6）**（ユーザー添付で確定） | **必須 `triangle`／階段 `rect`** |
| 葉下縁 | Pattern `1Eh` 系: ジグザグ／市松の下縁 | 部分的に `diag` |
| 幹 | **2〜3ドット幅**の縦棒。**白〜灰白（パレット7）** | `rect` |
| 地面との接点 | 切り判定の主領域 | — |
| 根元の斜面タイル | Pattern `65h`/`66h` のような階段三角 | **必須 `triangle`/`diag`**（使う場合） |

### 4.2 切断表現（原作＋ユーザー確定）

| 項目 | 原作（ODYSSEY） | 本プロジェクト |
|------|-----------------|----------------|
| 回数 | 左右各7回で片側切断、計14で倒木 | **片側5回で半分まで**。両側半分で木全体が消える |
| 途中ヒット | 当たった部分が**変色** | 根本接地付近のドットが **橙→赤** に変色 |
| **片側切断完了時** | その部分が**切れる** | **その側の根本ドットが消える（隙間）** ※ユーザー確定 |
| 両側切断後 | 倒木／消滅 | **点滅して消える**＋消滅音 |

## 5. イノシシ（猪）

### 5.1 見た目（ユーザー添付スクショ準拠）

| 項目 | 仕様 |
|------|------|
| 色 | **マゼンタ／ピンク1色**（パレット3） |
| 形 | **低く横長**。胴はほぼ矩形〜**前傾 `para`**。前方は尖った鼻（階段 or `diag`）。全体は「ずんぐりした充電ブロック」 |
| 斜め | 胴 **`para` 必須**。鼻先 **`diag` 必須** |
| 足 | **短い脚**（2〜4本の下向き1ドット）。走行で前後シフト2コマ |
| サイズ | おおよそ **9×4〜10×5** 論理ドット（与作より低く短い） |

### 5.2 動き・音・やられ

| 項目 | 仕様 |
|------|------|
| **出現** | **画面の左右端（端っこ）から**入場して突進。端に鼻先が見えてから入ってくる（ユーザー確定） |
| **突進音** | 出現／突進開始時に **専用SFX**（必須） |
| 接触 | 即ミス（天使） |
| 回避 | ジャンプ可（CV版で追加） |
| **撃破** | 振り下ろし直撃より、**早めに振って「斧が戻る」タイミングで当てる**（iyatsue） |
| 撃破演出 | 短い点滅のあと消滅（暫定） |
| 難易度 | 面が進むと極端に高速化 |

## 6. マムシ（地面から出る蛇）

### 6.1 見た目

| 項目 | 仕様 |
|------|------|
| 色 | マゼンタ系1色（スクショのギザギザ） |
| 出現 | **地面の下から這い出る**（縦にせり上がる） |
| 形 | ギザギザ／鋸歯。L字セグメント（Pattern 2Ch 系）の連結 |
| 斜め | 鋸歯エッジに **`diag` 必須** |

### 6.2 動き

| フェーズ1 | 地面から上昇（emerge） |
| フェーズ2 | 地上を横に移動（這う） |
| 接触 | 即ミス |
| 撃破 | 斧（向き方向）／ジャンプ回避 |

|------|--------|------|------|
